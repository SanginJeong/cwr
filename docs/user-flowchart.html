import 규칙은 eslint.config.mjs의 no-restricted-imports가 강제합니다. 슬라이스 밖에서는 index.ts로만 import할 수 있고, 아래 레이어만 import할 수 있으며, 같은 레이어의 다른 슬라이스는 import할 수 없습니다.

5. 정리 결과와 남은 일

  • 해결토큰 재발급 라우트를 src/app/api/auth/refresh/route.ts로 옮겨 401 인터셉터가 다시 동작하게 했습니다.
  • 해결dayjs, svgo, babel-plugin-react-compiler를 제거했습니다. devtools는 devDependencies로 옮겼습니다.
  • 해결미사용 파일(ScheduleDaySection, 빈 store·constants, 미사용 타입·배럴, useDebounce)을 삭제했습니다.
  • 해결FSD 구조로 옮겼습니다. 순환 import는 0건이고, 레이어 규칙 위반도 0건입니다.
  • 해결URL을 재설계하고 route group으로 나눴습니다. 경로는 ROUTES 상수로 모았습니다. middleware는 쿠키만 검사하고, 팀 관련 검사는 서버 컴포넌트에서 합니다.
  • 해결게시판 검색어와 정렬을 URL 쿼리(?q=, ?sort=)로 옮겼습니다.
  • 유지gsap은 랜딩 페이지에서만 쓰여 그대로 둡니다 (ADR-003).
  • 보류?date=를 yyyy-MM-dd로 바꾸는 작업은 서버의 날짜 해석을 확인한 뒤 진행합니다.
  • 남음실제 계정으로 전체 플로우를 수동 점검해야 합니다. 배포 후 문제가 없으면 redirects를 permanent: true로 바꿉니다.
생성 방법: page/layout/middleware 엔트리마다 정적 import와 dynamic import를 추적해 집계했습니다. 런타임 조건부 렌더링은 구분하지 않으므로 "도달 가능" 기준입니다.
