# QA: Supabase 모드 로그인 상태 (로드맵 H0)

> 실행일: 2026-10-06 · 브랜치: `feat/supabase-backend`
> 결과: **57개 항목 통과** (계정 8, 팀 10, 할 일 18, 게시판 21). QA 중 버그 8건을 찾아 고쳤습니다.

## 방법

- 임시 작업 폴더(git worktree)에서 `NEXT_PUBLIC_BACKEND=supabase`로 개발 서버를 띄웠습니다.
- 헤드리스 Chrome(puppeteer-core)으로 실제 화면을 조작했습니다.
- 결과는 **같은 계정으로 로그인한 Supabase 클라이언트로 DB를 조회해서** 확인했습니다. 화면 표시만 보고 판단하지 않았습니다.
- 임시 계정 2개(팀장 역할, 팀원 역할)는 SQL로 만들었습니다. Supabase가 테스트용 이메일 도메인을 거부하기 때문입니다. 확인이 끝난 뒤 계정, 팀, 게시글을 지웠습니다.
- 페이지마다 콘솔 에러와 페이지 에러를 모아서, 하나라도 있으면 실패로 봤습니다.

## 고치지 않은 것 (결정이 필요함)

1. **목록 화면의 "할 일 추가" 버튼이 실제로는 '할 일 목록'을 만듭니다.** 할 일 자체는 오른쪽 아래 ＋로 만듭니다. 문구를 "목록 추가"로 바꿀지 정해야 합니다.
2. **할 일을 수정할 때 설명이 비어 있으면 저장 버튼이 꺼집니다.** 만들 때는 메모가 선택인데 수정할 때는 필수인 셈입니다.
3. **할 일 만들기 모달의 반복 설정 선택지가 모달 아래에서 잘립니다.** "월 반복"은 모달을 스크롤해야 보입니다.

## 확인하지 않은 것

- 카카오 로그인 (H1에서 제거 예정)
- 비밀번호 재설정 메일 (이전에 직접 확인해 주심)
- 태블릿·모바일 화면에서의 조작 (레이아웃 캡처만 함)
- 접속 상태: 10분 뒤 자동 자리 비움, 여러 탭, 네트워크 재접속, 1시간 뒤 토큰 갱신 후 유지

## 남은 정리

- QA 중 올린 **이미지 16개가 Storage `images` 버킷에 남아 있습니다.** Storage 목록 조회 권한이 없어(앱에는 필요 없어서 만들지 않음) 계정으로는 지울 수 없었습니다. 대시보드 → Storage → images에서 폴더를 모두 선택해 삭제하면 됩니다. SQL로 테이블 행을 지우면 실제 파일이 남으므로 대시보드를 쓰세요.
